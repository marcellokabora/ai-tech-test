# AI Tech Test API

Local Express + TypeScript REST API implementing the three requested endpoints against `randomuser.me`.

## Quick start

```bash
npm install
copy .env.example .env # Windows; use cp on macOS/Linux
# Set LLM_API_KEY and optionally provider/model settings in .env
npm run dev
```

The API listens on `http://localhost:3000` by default. `LLM_BASE_URL` is OpenAI-compatible, so OpenRouter, OpenAI, or another compatible provider can be used. The LLM is required for `/users/summary` and `/users/filter`; those routes return an explicit error when it is not configured or unavailable.

## Endpoints

- `GET /users` fetches 50 users and returns the upstream JSON unchanged.
- `GET /users/summary` fetches 100 users and returns `{ "summary": "..." }`, generated by the configured external LLM.
- `POST /users/filter` accepts `{ "query": "Users older than 40" }`, fetches 300 users, asks the LLM for a structured filter, and applies that filter in backend code. Supported filter shapes are age greater-than/less-than/between and exact city.
- `GET /health` returns `{ "status": "ok" }`.

Errors use `{ "error": "...", "code": "..." }` with suitable HTTP status codes. Upstream and LLM calls have explicit failure handling and LLM requests time out.
